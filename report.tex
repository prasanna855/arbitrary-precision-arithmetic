\section*{Abstract}
This report is about a Java project to make a library that does math with very big numbers, both int and float. It can do add, subtract, multiply and divide with no loss in precision. We use strings to keep the digits and avoid normal data type limits.

\section*{Design}
I made two class: \texttt{AInteger} for big integers and \texttt{AFloat} for big float numbers. We used strings inside to keep the digits, so we can go bigger than normal int. We made functions for parsing string and for doing math operations.

\begin{itemize}
\item \texttt{AInteger}: it supports \texttt{+ - * /} and string input.
\item \texttt{AFloat}: it has integer part (using \texttt{AInteger}) and decimal part using \texttt{String}.
\end{itemize}

\section*{Implementation Overview}
We wrote our own add, subtract, etc using digit by digit logic. We split float numbers into two part - integer and decimal part. We made sure it handle minus sign and trailing zeros also. If the float is like 0.0000000000000001 we still keep it.

\section*{Limitations}
Still working on better float division. Also float multiply with lots of digits is slow. We not yet add rounding, we only cut at 30 digits.

\section*{Testing and Verification}
